- Rulings / conservative interpretations:
  - Engine selection and legacy flags (controller): `legacy_window_reset` restores the per-window loop unchanged; the continuous engine rejects `legacy_same_close` / `legacy_spread_pnl` (`ValueError`); `legacy_stale_prints` combines with either engine.
  - T9.1 is applied to the pair's training slice: β_w, the ≥ 60-row eligibility and the almgren cost (σ and the ADV of the last training day) of a window use its rows strictly before `oos_s`. The window-level ivol weights and the HMM fit still use the window loop's slice [tr_s, oos_s] (unchanged code, shared by both engines); they only act on decisions at or after the close of `oos_s`, so this is not look-ahead (HMM's Viterbi look-ahead is T9.3). Recorded for T9's verification.
  - `exit_signal` of the end-of-run close = the pair's last decision row (≤ the last `oos_e`); the fill is the next available close, so that close is causal like every other exit; `exit == exit_signal` only when no row with both legs follows up to `cfg.end`. `window_exited` = the window of that decision row (the last window unless the pair's data end before it).
  - An entry decided on the last decision row fills on the fill-only row (T1 rule) and is closed there at once by the end-of-run rule (held 0, gross 0, costs charged) — the literal rule and the conservative one; it never occurred in the placebo or real runs.
  - CUSUM: a window's statistic runs on its own z over its rows [tr_s, oos_e] exactly as before; from its break row the window opens nothing; an open trade (from this or an earlier window) is force-closed only by a break inside the window's OOS (a break in its training rows could not close anything before T3 either).
  - `window_exited` for an exit decided in a gap between OOS periods (step > oos) or on the last `oos_e` row = the latest-starting window whose OOS has begun.
  - Kalman exits use the rolling z (Z_WIN rows) of log p1 − β_e·log p2 recomputed per trade from the pair's first row; z values are not needed before the entry, so the start does not matter beyond float rounding.
  - `--metagate` / `--hrp` (R7) fail with the same `UnboundLocalError` in both engines (the train-trade harvest sits in the shared window loop).
  - The per-window lines of the continuous engine count trades by `window_entered`; `window` / `oos_start` keep their meaning for downstream code (entry window).
