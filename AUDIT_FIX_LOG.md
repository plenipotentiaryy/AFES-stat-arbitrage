- Rulings / conservative interpretations:
  - Capital (controller ruling, documented in the run header and tests/README.md): constant, len(pairs) of the run × 2.0 USD per $1 of leg-1 notional; pairs without data or trades count too (a larger capital, lower returns; the Sharpe is invariant). Ann. return = mean daily return × 252 (no compounding, constant capital).
  - Calendar (R2): every business day of the span, holidays as zero days — costs ≈ 0.012 Sharpe on real data (0.641 → 0.629) before the MTM itself (→ 0.455). Span end = max(last OOS end, last exit fill) (R16).
  - VWAP fills: the entry day is marked from the entry VWAP to that day's close (the position is held at the close), the exit day from the previous mark to the exit VWAP. A leg's mark moves only on its own print dates; borrow only on the pair's rows (both legs print), `borrow / held` per row, the count asserted equal to `held`.
  - `legacy_spread_pnl` requires `legacy_exit_date_pnl` (its spread PnL has no leg quantities to mark) — same pattern as T3's `legacy_window_reset` requirement.
  - Downstream scripts read the MTM file's `pnl` column (USD per $1 of leg-1 notional — the units their tables, formats and other columns use; ret = pnl / capital, so their Sharpe ratios, bootstrap CI, t-stats and R² are identical on either column); the % of capital figures are in the CLI summary and the MTM file's `ret`. `--split` still cuts the series (a no-op for the default 2014-12-31). With `--legacy-exit-date-pnl` the CLI writes no MTM file (the series would not be MTM).
  - Rule 4 in the CLI: the default stats carry no `sharpe_full` / `sharpe_exit`, and the cross-listed block line drops its exit-date "Sharpe(full)" outside legacy mode.
  - Review fix round 1 (R32, R33, amended into this commit): the dashboard showed a second, exit-date "Sharpe" of the same portfolio ("Non-cross (exit-date booking) (S=+0.63)" next to "Combined (S=+0.46)") → the CLI writes the per-pair MTM file and the dashboard computes every per-pair and sub-block Sharpe from it on block capital = its pairs × 2.0 (nothing from exit-date booking outside legacy mode); MTM-unit axis labels; the dashboard drawdown starts the equity at 0 (as `mtm_stats`); the loaders cross-check the MTM files against the trades file; the legacy downstream span stated above.
